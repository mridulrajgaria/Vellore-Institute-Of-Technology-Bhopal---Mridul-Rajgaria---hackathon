Module A: Rebalancer
Tactical Index Rebalancer Logic
Module A: Quantitative Rules, Parameters & Bounds
Dynamic conviction tilting across 14 large-cap US equities with institutional execution safeguards
Rebalancer Mathematical Parameters (rebalancer.yaml)
Parameter Value Financial Rationale & Formulation
w_base 7.14% Equal-weight anchor across 14 stocks ($1 / 14 = 7.14\%$).
tilt_factor (k) 1.50 Conviction scalar: $w_{\text{raw}, i} = w_{\text{base}} \times (1.0 + k \times \text{EMA}_i)$.
ema_half_life 2.0 Days Exponential memory filter preventing high-frequency noise churn.
deadband ±0.20 Threshold filter: scores inside $[-0.20, +0.20]$ zeroed out.
negative_multiplier 1.25× Asymmetric risk aversion: negative headlines receive $25\%$ higher penalty.
Portfolio Risk Boundaries & Friction Safeguards
Constraint Boundary Implementation Safeguard
Lower Weight Bound 3.57% (0.5×) Floor prevents complete asset divestment or short exposures.
Upper Weight Bound 14.29% (2.0×) Ceiling limits single-stock concentration risk (e.g. TSLA).
Turnover Cap 10% / Day Clamps daily two-way volume to eliminate excessive transaction drag.
Transaction Frictions 5 bps Institutional execution cost deducted on all turnover in net NAV.
Fallback Behavior Equal Weight Missing market data gracefully reverts allocations back to $7.14\%$.
